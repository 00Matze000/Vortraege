## Struktur

```
.
├── index.html        Landing-Page mit Auswahl
├── Vortrag1/         Keras 3 — TensorFlow · PyTorch · JAX
```

Jeder Vortrag ist eine eigenständige scroll-basierte HTML-Seite mit eigenem CSS und JS. Keine Build-Schritte, einfach im Browser öffnen.

## Stack

- Vanilla HTML / CSS / JavaScript
- [Three.js](https://threejs.org/) für 3D-Visualisierungen (Hardware-Modelle in Vortrag 1, Loss-Landschaften in Vortrag 2)
- DM Serif Display · DM Sans · JetBrains Mono via Google Fonts

GitHub Pages aus dem `main`-Branch. Änderungen gehen nach Push automatisch live.
